Vos données, sur l’instance que vous choisissez

MySold fonctionne avec une API Flask et une base PostgreSQL, déployées avec Docker Compose. Aucun compte Firebase, connexion Google ni service cloud applicatif n’est obligatoire. Les transactions sont saisies ou importées par l’utilisateur : MySold ne se connecte pas automatiquement à votre banque.

La connexion utilise un mot de passe, avec une double authentification TOTP facultative. Les documents financiers sont chiffrés au repos côté serveur ; ce n’est pas un chiffrement de bout en bout. L’exploitant de l’instance gère l’hébergement et les sauvegardes.

Questions fréquentes

Faut-il installer une application Android ?

Non. MySold fonctionne dans le navigateur. L’installation en PWA est facultative et conserve l’utilisation du serveur de cette instance.

La démonstration utilise-t-elle mes données ?

Non. La démonstration séparée utilise des comptes et opérations fictifs. Ses changements restent en mémoire et disparaissent au rechargement.

Puis-je récupérer mes informations ?

L’application propose un export CSV, une restauration compatible et des rapports PDF. La suppression du compte et des données actives est disponible dans les paramètres de sécurité. Exportez vos données avant une suppression.

Le code est-il librement redistribuable ?

Le code source est consultable. Les droits d’utilisation, de modification et de redistribution sont définis par la licence du dépôt.
